# HYBRID // TRAIN

เว็บแอปออกกำลังกายแบบ PWA ธีมอวกาศนีออน สำหรับ iPhone ใช้งานฟรีบน Vercel พร้อม Supabase สำหรับบัญชีผู้ใช้ หลายโปรแกรม และการติดตามเพื่อน

เป็น static site ล้วน ไม่มี build step ไม่มี dependency ที่ต้องติดตั้ง — ES modules + CSS ธรรมดา และ Supabase โหลดจาก CDN

## เปิดใช้ Login + Database

1. สร้างโปรเจกต์ฟรีใน [Supabase](https://supabase.com/dashboard)
2. เปิด **SQL Editor** แล้วรันไฟล์ `supabase/schema.sql` ทั้งไฟล์ (รันซ้ำได้ปลอดภัย — ใช้ `if not exists` ทั้งหมด)
3. จาก **Project Settings → API** คัดลอก Project URL และ Publishable key (หรือ anon key)
4. ใส่ค่าทั้งสองใน `supabase-config.js` โดยห้ามใช้ `service_role` key
5. ใน **Authentication → URL Configuration** เพิ่ม URL ของ Vercel เป็น Redirect URL
6. Deploy ใหม่บน Vercel

> อัปเกรดจากเวอร์ชันก่อน: ต้องรัน `supabase/schema.sql` ใหม่อีกครั้ง เพราะมีตาราง `training_progress_summary`, `training_activity` และคอลัมน์ `onboarded_at`, `share_progress` เพิ่มเข้ามา

เมื่อเชื่อมแล้ว ครั้งแรกที่เข้าใช้จะมีหน้าตั้งค่าเริ่มต้น 6 ขั้น ให้เลือกโปรแกรม วันเริ่ม ค่าตั้งต้นของร่างกาย เบนช์มาร์ก และความเป็นส่วนตัว

## สิ่งที่มีในแอป

**การฝึก**
- ตาราง 12 สัปดาห์จากไฟล์ Hybrid Aesthetic Calisthenics + Marathon
- โปรแกรม Upper A, Lower + Core, Upper B, recovery และแผนวิ่ง
- บันทึกจำนวนครั้งและน้ำหนักรายเซ็ต พร้อมตัวจับเวลาเซ็ตและเวลาพัก (45–180 วินาที) และเสียงแจ้งเตือน
- บันทึกการวิ่ง ระยะทาง เวลา และ RPE
- สร้างโปรแกรมเอง และ Import/Export ข้อมูล

**แดชบอร์ด**
- KPI: สัปดาห์ปัจจุบัน เซสชันที่ทำเสร็จ สตรีค ระยะวิ่งสะสม/ไกลสุด
- กราฟความสำเร็จ 12 สัปดาห์ (จุดม่วง = สัปดาห์ deload)
- กราฟระยะวิ่งจริงเทียบแผน Long Run
- ร่างกาย: น้ำหนัก รอบเอว อก ไหล่ ต้นแขน ต้นขา ไขมัน พร้อมกราฟแนวโน้ม
- เบนช์มาร์ก: Pull-up / Dip / Push-up สูงสุด, L-Sit, Handstand, 5K พร้อมส่วนต่างจากค่าตั้งต้น

**เพื่อน**
- ค้นหาด้วยชื่อผู้ใช้ (เฉพาะคนที่เปิดให้ค้นหา) ส่ง/รับ/ปฏิเสธคำขอ และลบเพื่อนได้
- เห็นความคืบหน้าของเพื่อน: สัปดาห์ที่เท่าไร ทำไปกี่เซสชัน ระยะวิ่งสะสม สตรีค และกราฟ 12 สัปดาห์
- เห็นว่าเพื่อน **กำลังทำอะไรอยู่ตอนนี้** แบบเรียลไทม์ เช่น “กำลังทำ Upper A · Pull-up · เซ็ต 3/4 · 22 นาที”

**อันดับ**
- จัดอันดับคุณกับเพื่อนได้ 4 แบบ: ความสำเร็จสัปดาห์นี้ · สตรีค · ระยะวิ่งสะสม · สัปดาห์ของบล็อก
- แถวของคุณถูกไฮไลต์ อันดับ 1–3 ได้เหรียญ และคนที่ปิดการแชร์จะอยู่ท้ายเสมอ
- เข้าได้จากปุ่มสลับ **เพื่อน / อันดับ** ที่ด้านบนทั้งสองหน้า หรือจาก **ตั้งค่า → อันดับ**

**ความเป็นส่วนตัว** — เพื่อนไม่เคยเห็นอีเมล จำนวนครั้ง น้ำหนักที่ยก หรือการวัดร่างกายของคุณ ข้อมูลเหล่านั้นอยู่ในตารางที่เจ้าของเท่านั้นอ่านได้ (RLS) ปิดการแชร์ได้ที่ **ตั้งค่า → แก้ไขโปรไฟล์**

## ธีม

พื้นหลังเป็น canvas อวกาศ ที่ **แต่ละเซสชันของสัปดาห์คือดาวหนึ่งดวง** — ทำเสร็จแล้วดาวจะสว่างตามสีของประเภทการฝึก และเส้นจะเชื่อมกันทีละช่วงจนกลายเป็นกลุ่มดาวเมื่อจบสัปดาห์ ตำแหน่งดาวคำนวณจาก hash ของวันที่+ชื่อเซสชัน จึงอยู่ที่เดิมเสมอ

เคารพ `prefers-reduced-motion` — ถ้าเปิดไว้ ทุกอย่างจะหยุดนิ่ง

## พัฒนาต่อ

ES modules ต้องเสิร์ฟผ่าน HTTP (เปิดไฟล์ตรง ๆ ด้วย `file://` จะไม่ทำงาน):

```bash
npx serve .
```

โครงสร้างโค้ด ระบบ token และคอมโพเนนต์ทั้งหมดอธิบายไว้ใน [DESIGN.md](DESIGN.md)

## Deploy บน Vercel

1. สร้างบัญชีฟรีที่ [vercel.com](https://vercel.com)
2. อัปโหลดโฟลเดอร์นี้ไปยัง GitHub repository ใหม่ (หรือใช้ Vercel CLI)
3. ใน Vercel กด **Add New → Project** แล้วเลือก repository นั้น
4. กด **Deploy** โดยไม่ต้องตั้งค่า Build Command หรือ Framework
5. เปิดลิงก์ที่ Vercel ให้ด้วย Safari บน iPhone แล้วกด **Share → Add to Home Screen**
